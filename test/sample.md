# bookchoy.nvim sample

Hover over a Chinese character below with `K`. Press `K` again (Neovim's
default behavior) to focus into the float. From either the parent buffer or
inside the float, press `<C-k>` / `<C-j>` to cycle alternate matches. With
the cursor on a highlighted cross-reference inside the float, press `gd` to
jump to that word.
